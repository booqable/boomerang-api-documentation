# Booqable Interop

The sections below only apply if your app has its own backend: [OAuth](#booqable-interop-oauth) lets it call Booqable's API on a user's behalf, [Signed requests](#booqable-interop-signed-requests) lets it check that a request really comes from Booqable, [Frames](#booqable-interop-frames) covers the rules its pages run under inside Booqable, and [Webhooks](#booqable-interop-webhooks) let it react to events without polling.
