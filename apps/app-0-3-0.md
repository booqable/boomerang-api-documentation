# Reference

## `booqable.json`

Schema for the configuration file that defines Booqable apps.

```jsonc
{
  "$schema": "https://developers.booqable.com/schemas/app-0-3-0.json#",
  "id": "liquid_conf",
  "version": "1.0.0",
  "name": "MyApp",
  "author": "Booqable",
  "app_store": { /* AppStoreInfo */ },
  "plans": [ /* ... */ ],
  "configuration_page": { /* ConfigurationPage */ },
  "main_page": { /* MainPage */ },
  "status": { /* AppStatus */ },
  "tracking_script": { /* TrackingScript */ },
  "theme_blocks": [ /* ... */ ],
  "oauth": { /* OauthConfig */ },
  "base_url": "https://example.com",
  "payments": { /* PaymentsConfig */ },
  "required_apps": [ /* ... */ ],
  "lifecycle": { /* Lifecycle */ }
}
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `$schema` | constant: `"https://developers.booqable.com/schemas/app-0-3-0.json#"` | true | Schema version for the app configuration. |
| `id` | string | true | Unique identifier for the app, used internally. |
| `version` | string | true | Version number or status of the app. |
| `name` | string | true | Internal name for the app, not shown to end users. |
| `author` | string | true | Name of the app developer or company. |
| `app_store` | [`AppStoreInfo`](https://developers.booqable.com/apps.html#reference-appstoreinfo) | true |  |
| `plans` | array of [`AppPlan`](https://developers.booqable.com/apps.html#reference-appplan) | false | Subscription plans for the app. |
| `configuration_page` | [`ConfigurationPage`](https://developers.booqable.com/apps.html#reference-configurationpage) | false | Defines a UI for configuring the app. |
| `main_page` | [`MainPage`](https://developers.booqable.com/apps.html#reference-mainpage) | false | An embedded page for the daily operations of the app. |
| `status` | [`AppStatus`](https://developers.booqable.com/apps.html#reference-appstatus) | false | Options controlling the app status reported inside Booqable. |
| `tracking_script` | [`TrackingScript`](https://developers.booqable.com/apps.html#reference-trackingscript) | false | Settings for apps that provide tracking scripts meant to be installed in store pages. |
| `theme_blocks` | array of [`ThemeBlock`](https://developers.booqable.com/apps.html#reference-themeblock) | false | Website blocks provided by this app for use in the website editor. |
| `oauth` | [`OauthConfig`](https://developers.booqable.com/apps.html#reference-oauthconfig) | false | OAuth integration for apps that require Booqable to grant access on behalf of the user. |
| `base_url` | string | false | Base URL to use when providing relative URLs elsewhere in this configuration file. |
| `payments` | [`PaymentsConfig`](https://developers.booqable.com/apps.html#reference-paymentsconfig) | false | Payment integration for apps that process charges, authorizations, and refunds. |
| `required_apps` | array of [`RequiredApp`](https://developers.booqable.com/apps.html#reference-requiredapp) | false | Other Booqable apps that must be installed before this app can be installed. The app store shows the requirement (and the required app's price) up front and blocks installation until it is met. |
| `lifecycle` | [`Lifecycle`](https://developers.booqable.com/apps.html#reference-lifecycle) | false | Customizes what merchants see at moments of the app's install lifecycle. |
## `AppStoreInfo`

Information about the app to display in the app store.

```jsonc
{
  "title": { /* LocalizableString */ },
  "description": { /* AppStoreDescription */ },
  "categories": [ /* ... */ ],
  "icon": { /* AssetReference */ },
  "features": [ /* ... */ ],
  "website": { /* Link */ },
  "youtube": "4tDyXghOQbI",
  "setup_minutes": 2,
  "support": { /* AppStoreSupport */ }
}
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `title` | [`LocalizableString`](https://developers.booqable.com/apps.html#reference-localizablestring) | true |  |
| `description` | [`AppStoreDescription`](https://developers.booqable.com/apps.html#reference-appstoredescription) | true |  |
| `categories` | array of one of: `accessibility`, `accounting`, `crm`, `fulfillment`, `maps`, `marketing`, `payment`, `social`, `tracking`, `translation`, `website`, `widget` | false | Category classification for organizing apps in the app store. |
| `icon` | [`AssetReference`](https://developers.booqable.com/apps.html#reference-assetreference) | true |  |
| `features` | array of [`LocalizableString`](https://developers.booqable.com/apps.html#reference-localizablestring) | false | Bulleted list of key features shown on the app's store page. |
| `website` | [`Link`](https://developers.booqable.com/apps.html#reference-link) | false | Product or marketing website link shown in the app's store page. |
| `youtube` | string | false | YouTube video ID for an embedded overview/promo video to be shown in the app's store page. |
| `setup_minutes` | integer | false | Estimated time in minutes to install and set up the app. |
| `support` | [`AppStoreSupport`](https://developers.booqable.com/apps.html#reference-appstoresupport) | false |  |
